 # AlibabaCloud-Skills

 阿里云官方技能合集（精选 28 个，来源：魔搭社区 alibabacloud-skills/AlibabaCloud-Skills）

 ---

 **alibabacloud-find-skills**：阿里云技能发现
 搜索、发现和浏览阿里云 Agent 技能，支持"为 X 找一个技能""阿里云有什么 skill"等自然语言查找。

 **alibabacloud-quickbi-smartq**：Quick BI 智能问数
 文件问答（上传 Excel/CSV 智能分析）与 Quick BI 平台数据集自然语言问答。

 **alibabacloud-data-agent-skill**：飞天数据分析 Agent
 通过 CLI 调用飞天 Data Agent for Analytics，对企业数据库进行自然语言驱动的数据分析。

 **alibabacloud-dataworks-data-agent**：DataWorks 数据 Agent
 与 DataWorks Data Agent 对话式数据分析，支持会话生命周期管理和结果产物下载。

 **alibabacloud-odps-sql-generation**：MaxCompute SQL 生成
 MaxCompute SQL 智能生成，覆盖 text2sql 转换原则、方言语法差异（DQL/DDL/DML）及 Top N、PIVOT、窗口函数等常用查询模板。

 **alibabacloud-odps-maxframe-coding**：MaxFrame 开发辅助
 MaxCompute（ODPS）上 MaxFrame SDK 开发与文档导航，解答 API/概念/pandas 兼容接口问题并辅助编写数据处理代码。

 **alibabacloud-analyticdb-mysql-copilot**：AnalyticDB MySQL 运维诊断助手
 集群信息查询、性能监控、慢查询诊断、运行中 SQL 分析和表级优化建议。

 **alibabacloud-dms-skill**：DMS 数据库读写
 在 DMS 中检索目标数据库并执行 SQL 查询与数据变更。

 **alibabacloud-sls-query**：SLS 日志查询分析
 SLS 日志查询与分析，辅助编写、解释、优化、执行和排错索引查询、SQL 分析与 SPL 扫描/管道语句。

 **alibabacloud-dataworks-datastudio-develop**：DataWorks 数据开发
 创建、配置、校验、发布、更新、移动和重命名节点与工作流，管理组件、文件资源与 UDF 函数，覆盖 Shell/SQL/Python 等 150+ 节点类型。

 **alibabacloud-docmind-parse**：DocMind 文档解析
 智能文档解析，支持 PDF、Word、PPT、Excel、图片等，输出结构化 Markdown/JSON/HTML。

 **alibabacloud-iqs-search**：IQS 实时联网搜索
 基于阿里云 IQS API 的实时网页搜索与页面阅读，用于获取最新信息、新闻、事实核查、URL 内容提取和网页调研。

 **alibabacloud-cleversee-search**：Cleversee 神经搜索
 面向 AI/Agent 的通用联网搜索，提供高质量、低延迟的神经语义检索与网页内容抓取。

 **alibabacloud-error-troubleshoot**：OpenAPI 报错排查
 基于 Request ID、错误码或错误信息诊断阿里云 API 调用失败（通过 aliyun CLI openapiexplorer 插件）。

 **alibabacloud-cli-guidance**：阿里云 CLI 使用指导
 指导使用 aliyun CLI 管理云资源，覆盖 CLI 安装、凭证配置、插件管理、命令构建和报错排查。

 **alibabacloud-agentloop-contextstore**：AgentLoop 上下文存储
 通过 aliyun CLI 操作云监控（CMS）AgentLoop ContextStore，为 Agent 提供上下文、记忆与经验的存储管理。

 **alibabacloud-tablestore-openclaw-memory**：Tablestore 长期记忆
 安装配置 Tablestore Mem0 插件，以表格存储（Tablestore）作为 mem0 向量存储后端，为 AI Agent 提供持久化长期记忆。

 **alibabacloud-tablestore-agent-storage**：Tablestore Agent 存储
 使用 tablestore-agent-storage Python SDK 构建和管理基于表格存储的知识库。

 **alibabacloud-devops**：云效 DevOps 自动化
 自动化云效 DevOps 任务：创建运行流水线、管理代码库与合并请求、跟踪工作项与迭代、管理测试用例、制品和应用发布。

 **alibabacloud-yunxiao-flow-analysis**：云效流水线诊断
 云效 Flow 流水线故障排查，诊断构建错误、运行失败、主机部署失败等问题并给出修复建议。

 **alibabacloud-terraform-code-generation**：Terraform 代码生成
 为阿里云基础设施生成 Terraform HCL 代码，覆盖 VPC、ECS、RDS、OSS、SLB/ALB、函数计算 v3、ACK 等资源。

 **alibabacloud-oos-template-generation**：OOS 模板生成
 OOS 运维编排服务模板智能生成，根据自然语言描述创建自动化编排模板。

 **alibabacloud-mcp-core-script-generate**：MCP Core 脚本生成
 从自然语言云操作需求生成兼容阿里云 MCP Core RunScript 的 Python 脚本。

 **alibabacloud-ecs-diagnose**：ECS 实例诊断
 ECS 实例综合诊断，包括云平台状态检查和通过云助手进行 GuestOS 内部诊断的系统化排障。

 **alibabacloud-sysom-diagnosis**：Linux 系统诊断
 Linux 服务器性能与稳定性问题排查：CPU 打满、高负载、调度延迟、内存压力、OOM、页缓存异常等。

 **alibabacloud-openclaw-skill-security-scan**：技能安全扫描
 扫描已安装技能的安全风险并审计平台配置，用于技能审计、健康检查和安全基线检查。

 **alibabacloud-safety-checker**：内容安全检测
内容安全审核与 AI 安全护栏的自动化测试，支持多服务对比、requestId/traceId 追踪和漏报深度分析。

 **alibabacloud-remote-skills-connector**：远程技能连接器
 查询可用的阿里云托管远程技能并进行能力接入，支持远程技能调用的检查、查询与诊断。
