# MCP 目录与管理

侧边栏 `/mcp` 是所有角色共用的只读目录。管理员后台 `/admin/mcp` 独立提供服务管理、可见范围、工具风险审核及源码预览。

## 可见范围

未开启“限定可见”时，启用且未删除的服务向所有角色开放。开启后角色与个人名单取并集；空名单意味着全员不可见，管理员仍可后台管理。Agent 的绑定与工具白名单不被扩展。实际可用服务取绑定、启用和用户授权的交集，执行边界也会重新验证，撤销权限对后续调用生效。

## 工具说明与风险

服务和工具的中文展示说明在后台使用轻量模型生成并存入数据库，目标约40至55字，说明功能与用途，不修改 Agent 使用的原始描述。页面读取不调用模型；生成失败保留旧展示说明或清理后的原始说明。原始信息或展示生成版本变化可重新生成，失败结果不会在每次重启反复调用模型。

管理员可将任何工具标为高或低风险。高风险要求现有逐次确认；操作类名字不再覆盖管理员低风险审核。新增工具及输入输出结构变更仍要求审核，Agent 白名单和参数安全检查不变。

## 源码

仅管理员可以只读预览完整 Python 源文件及注释。点击工具名在当前页面最外层打开大尺寸固定弹窗，代码内部滚动并定位到对应函数；关闭后保留原工具列表。重新枚举按钮位于工具抽屉标题栏右侧。自动定位本地 `app/agents/mcp_servers` 中注册脚本。远程服务可由受控部署配置关联源码：`mcp_servers.source_files` 按工具名（或 `*`）记录 `path`/`url` 和可选 `origin`。本地关联文件必须位于后端 `mcp_sources` 目录或上述内置目录。

远程下载仅允许 `MCP_SOURCE_REVIEWED_URLS` JSON 数组中的精确 HTTPS Python 文件地址，不允许跳转、查询参数或传递 MCP 凭据；每个文件最多 1 MB。无可靠来源或无法定位函数时说明不可获取，不生成伪代码。源码关联应由维护人员验证与实际服务版本相符，不能用同名文件代替真实源码。远程服务的源码快照（若有）随镜像保存并按精确服务 URL 与 SHA-256 校验关联，服务升级后必须重新核对和更新快照。

## 迁移与持久化

执行 `python migrate_mcp_governance_v2.py` 可预览，添加 `--apply` 才落库；迁移幂等，不重置原有配置。部署源码、后端/前端镜像和 Coolify Compose 同步保存，数据库与运行目录保留原持久化挂载。

`migrate_mcp_display_v3.py` 为服务增加独立展示说明列，同样先预览、`--apply` 落库且幂等。侧边栏连接恢复显示本地命令与脚本或远程地址，环境变量不展示，内嵌凭据和 URL 查询参数不公开。
